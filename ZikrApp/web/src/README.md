# Web build sources

- `app.html` – the app shell, styles and logic
- `data.json` – the dua library and the 99 Names
- `reflections.js`, `more_topics.js` – reflection topics; `hadith.js` – which hadith backs each dhikr
- `art.js` – animated illustrations (shapes only, no faces)
- `sources.js` – **generated**: authentic Quran and hadith text for every reference

## Refreshing authentic texts

`sources.js` is produced by `pull_sources.py` from:
- Quran: the npm package `quran-json` (Uthmani text from QuranEnc / King Fahd Complex,
  Saheeh International English, Tanzil transliteration)
- Hadith: the npm package `hadith` (the sunnah.com collection data: Arabic, English, grading)

```bash
npm pack quran-json@3.1.2 && tar xzf quran-json-3.1.2.tgz -C qj
npm pack hadith && tar xzf hadith-*.tgz -C hadith
python3 pull_sources.py . qj/package/dist hadith/package/data/hadith.db sources.js
python3 build.py   # writes the single-page app
```
The script keeps each cited hadith number and prints any whose wording differs a lot
from the summary, so they can be checked by hand.

## Quran reader

`quran.js` (the whole Quran for the reader) is generated by `build_quran.py`: Arabic and English from `quran-json`, transliteration from Quran.com's word-by-word data (standard scheme: dh, th, ʿ, ā ī ū):

```bash
npm pack @kmaslesa/holy-quran-word-by-word-full-data && tar xzf kmaslesa-holy-quran-word-by-word-full-data-*.tgz -C wbw
python3 build_quran.py qj/package/dist wbw/package/data.json quran.js
```

## Tafsir (loaded on demand)

The reader's tafsir view fetches `tafsir/{ik|mx}/{surah}.json` next to the page. These files are
**not committed** (Tafsir Ibn Kathir's English edition is a copyrighted publication); rebuild them with:

```bash
for ed in en-tafisr-ibn-kathir en-tafsir-al-mukhtasar; do mkdir -p taf/$ed
  for s in $(seq 1 114); do curl -sSf -o taf/$ed/$s.json \
    https://raw.githubusercontent.com/spa5k/tafsir_api/main/tafsir/$ed/$s.json; done; done
python3 build_tafsir.py taf ../tafsir
```
Source: spa5k/tafsir_api (data from Quran.com / Tarteel QUL). `ik` = Tafsir Ibn Kathir (abridged
English), `mx` = Al-Mukhtasar (Tafsir Center for Quranic Studies). Ibn Kathir's repeated passages are
stored once per surah (`p`) with a per-ayah index (`m`).
