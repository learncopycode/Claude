# Apps

This repository holds two separate apps, each in its own folder:

| Folder | App |
|---|---|
| [`NoteTok/`](NoteTok/) | **NoteTok** – your notes, TikTok style: paste a screenshot and AI turns it into a scrollable short. |
| [`ZikrApp/`](ZikrApp/) | **Zikr** – dhikr counter, Hisn al-Muslim, the Quran, after-prayer adhkar, prayer times and the adhan (web app and iPhone app). |

With GitHub Pages on (Settings → Pages → this branch, folder `/ (root)`):
- NoteTok: https://learncopycode.github.io/Claude/NoteTok/
- Zikr: https://learncopycode.github.io/Claude/ZikrApp/app/

`.github/workflows/ios-testflight.yml` builds the Zikr iPhone app (GitHub only runs workflows from that folder).
